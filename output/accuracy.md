# 정답지 대비 탐지 정확도

- 심은 패턴 22건 중 **20건 탐지** (재현율 91%)
- 탐지된 직원 21명 중 패턴을 심은 직원 21명, 심지 않은 직원 0명
- 전체 탐지 28건 = 심은 패턴 20건 + 함께 나타나는 부수 패턴 6건 + 심지 않은 패턴 2건

| 패턴 | 심은 수 | 찾은 수 |
|---|---|---|
| 장시간 근로 반복 | 4 | 4 |
| 특정 주 근로시간 급증 | 4 | 4 |
| 반복 지각 | 4 | 3 |
| 특정 요일 편중 | 3 | 2 |
| 지각 증가 추세 | 2 | 2 |
| 무단결근 반복 | 3 | 3 |
| 휴일 전후 결근 | 2 | 2 |

## 놓친 패턴
- 권윤아(모바일QA) - 특정 요일 편중
- 조민재(게임운영) - 반복 지각

## 심지 않았는데 탐지된 패턴
- 조민재(게임운영) - 특정 요일 편중: 화요일 3/5건
- 황세영(게임운영) - 지각 증가 추세: 이전 4주 1회 → 최근 4주 5회
